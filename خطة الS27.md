```

```

# القرارات التقنية الملزمة في S27

## لغة التنفيذ الأساسية: Python

استخدم Python للآتي:

```
AI orchestrationProvider adaptersModel routingMemoryRetrievalContext buildingAI workersMedia intelligenceSpeech / Vision integrationsMCP client adaptersEvaluationCost accounting
```

السبب:

- معظم AI/ML SDKs تعطي Python دعمًا ممتازًا.

- المشروع نفسه يستخدم FastAPI.

- Pydantic مناسب جدًا لعقود AI.

- async Python مناسب للـprovider calls المتوازية.

- FFmpeg والأدوات الثقيلة تنفذ native أصلًا؛ Python فقط orchestrator.

لا تستخدم Python لمعالجة pixels/audio samples يدويًا عندما يستطيع FFmpeg/library native فعل ذلك.

## TypeScript

يبقى مسؤولًا عن:

```
Remotion runtimegenerated AI DTOsfuture GUI SDKcross-language contract tests
```

ممنوع تعريف نفس AI contract يدويًا في Python وTypeScript.

## Contract Authority

السلطة تكون:

```
Pydantic model     ↓JSON Schema generated     ↓generated TypeScript types
```

أو equivalent generator موحد.

كل AI output الذي يدخل Domain/Core يجب أن يكون Structured Contract.

لا:

```
dict[str, Any]
```

في الحدود المهمة.

ولا:

```
"اطلب من المودل يرجع JSON"
```

فقط.

Structured Outputs/schema enforcement يجب استخدامه عندما يدعمه Provider. عند عدم دعمه:

```
provider response↓strict schema validator↓accept / reject
```

OpenAI توصي باستخدام Structured Outputs بدل JSON mode عندما يكون متاحًا، وتوصي أيضًا بتوليد الـschema من types أو العكس لتجنب divergence.

## Persistent Memory

استخدم:

```
PostgreSQL+pgvector+Object Storage
```

ولا تضف Vector DB منفصلة في S27.

PostgreSQL:

```
structured memorypreferencesconversation summariesAI runsmodel registrycostsmetadataembeddings
```

Object Storage:

```
large transcriptsframe analyseslarge structured media reportsgenerated mediamodel artifacts if needed
```

`pgvector` يدعم exact search افتراضيًا وHNSW/IVFFlat لاحقًا. ابدأ Exact + tenant filters ثم أضف HNSW فقط بعد benchmark فعلي.

## Observability

الـinstrumentation الأساسي:

```
OpenTelemetry
```

مع Langfuse كـAI observability/evaluation backend اختياري موصى به.

OpenTelemetry يوفر semantic conventions مشتركة للـtraces/metrics/logs، بما فيها GenAI operations، وLangfuse يستطيع استقبال OTEL مباشرة.

لا تجعل Langfuse Source of Truth.

# S27.10 — Durable AI Orchestration

لا تجعل:

```
FastAPI request↓await 12 AI calls↓hope process stays alive
```

العمليات القصيرة جدًا يمكن synchronous.

الـAI workflows الكبيرة:

```
AIRun↓AIStep[]↓durable worker
```

كل Step له:

```
PENDINGRUNNINGSUCCEEDEDFAILEDCANCELLEDWAITING
```

ومع:

```
attemptleaseheartbeatinput_hashoutput_refcostprovidermodel
```

## DAG

يدعم:

```
A├── B├── C└── D
```

ثم:

```
B + C + D↓E
```

فيمكن تشغيل المستقل بالتوازي.

لا تستخدم speculative multi-model execution افتراضيًا.

## External Calls

كل provider/MCP call تعامل كـdurable Activity:

```
idempotencytimeoutretryresult persistence
```

Temporal يفرض مبدأ مشابهًا: العمليات غير deterministic مثل APIs وLLMs وDB الخارجية توضع خارج replay workflow في Activities. نأخذ المبدأ، لكن لا نضيف Temporal نفسه في S27 لأن عندك أصلًا durable workers.

## اختبار الخروج

Fault injection:

```
kill worker during LLM callkill after provider success before DB commitkill after DB commit before next stepprovider timeoutprovider returns 500
```

Expected:

```
no duplicate expensive generationno lost AI runsafe resume
```

# Go / No-Go لـS27

لا تعتبر S27 ناجحة إلا إذا تحققت كلها:

[ ] AI يمكنه العمل مع أكثر من Provider دون تغيير Domain Services.

[ ] كل capability لها contract مستقلة عن provider.

[ ] Model Router يستطيع fallback/escalation.

[ ] Premium model لا يكون hard-coded.

[ ] Budget reservation يمنع concurrent overspend.

[ ] كل AI call لها cost/latency/provider/model trace.

[ ] جميع model outputs المهمة schema-validated.

[ ] Memory موجودة خارج المودل.

[ ] Project memory لا تنسخ Source of Truth.

[ ] pgvector/retrieval tenant-scoped.

[ ] zero cross-tenant memory leakage.

[ ] Context Builder deterministic ومحدود الحجم.

[ ] AI لا يستطيع استدعاء Domain mutation بدون Authorization Policy.

[ ] MCPs مصنفة ومقيدة.

[ ] worker restart لا يفقد AI workflow.

[ ] expensive calls idempotent/cacheable حيث يسمح العقد.

[ ] media analysis لا يعاد لنفس asset/version بلا داعٍ.

[ ] STT له benchmark خاص بالمشروع.

[ ] Vision له benchmark خاص بالمشروع.

[ ] Provider outage له fallback معلوم.

[ ] Eval suite تمنع ترقية Model أسوأ.

[ ] Prompt versions مسجلة.

[ ] AI traces لا تحتوي secrets افتراضيًا.

[ ] Fault injection كاملة خضراء.

[ ] Production-like multi-tenant E2E خضراء.
