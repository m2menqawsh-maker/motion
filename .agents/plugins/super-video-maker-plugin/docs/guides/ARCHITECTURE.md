# البنية الجديدة للمشروع (v2.0)

## المبادئ الأساسية

1. **المنسق المركزي**: `scripts/pipeline.py` هو الحاكم الوحيد لمسار الإنتاج.
2. **عقد البيانات**: `contracts/blueprint.ts` هو المرجعية للمخطط.
3. **الحالة المستمرة**: `.pipeline_state.json` هو مصدر الحقيقة لحالة المشروع.
4. **المهارات في مكان واحد**: `skills/INDEX.md` هو البوابة الوحيدة للمهارات المدعومة بالبوابات.

## البنية

```
templates/          # القوالب الموحدة (مصدر الحقيقة)
├── scenes/             # مشاهد كاملة
├── elements/           # عناصر داخل المشهد
└── effects/            # تأثيرات وانتقالات

ground-truth/           # الفهارس المرجعية
├── collections/        # مجموعات استخدام
└── CANONICAL_PATHS.json

skills/                 # المهارات
├── INDEX.md
├── super-video-maker/
├── remocn/
└── snapcn/
```

## المنسق الرسمي
يجب أن تتم عملية الرندر وتمرير البوابات عبر:
```bash
python scripts/pipeline.py <project_id>
```
ممنوع استخدام أساليب بديلة لتوليد الفيديو.
