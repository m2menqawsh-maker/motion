# قاموس اللقطات السينمائية (Cinematic Shot Recipes)

هذا القاموس يربط مصطلحات "التوقيع الإخراجي v2" بمكونات حقيقية موجودة في فهارس القوالب (TEMPLATE_INDEX / CINEMATIC_INDEX).

| مصطلح التوقيع v2 | المكون الفعلي (من الفهارس) |
|---|---|
| **Kinetic RTL Tracking** | WordStagger أو Captions + CameraRig (pan) |
| **Word-Chase Zoom** | AutoZoom أو interpolate + word lock |
| **Neon Ring** | Spotlight / SpotlightCard (أو رقِّ من onda) |
| **Marker Underline** | Underline / marker-highlight |
| **Highlighter BG** | Highlight / text-highlight |
| **Strikethrough** | strikethrough-replace |
| **Flash Cut** | Flash / pulse (engine/primitives) |
| **Square Framed Window** | Window / LayoutWindow (engine) |
| **Split Screen** | SplitScreen (templates) |
| **Dynamic Typography** | أي قالب من templates/elements/typography/ على خلفية داكنة |
| **Zoom-into-Glyph (Dive)** | CameraRig + AutoZoom (dive) |
| **Whip Pan** | whip-pan (templates/effects/transitions) |
| **Zoom-Out Reveal** | CameraRig (pull back) |
| **Parallax Depth** | parallax-layers (remotion/primitives) |
| **Diegetic CTA (Bookmark click)** | أيقونة + Click animation مقفول على كلمة |
| **Diegetic CTA (Laptop opens)** | LaptopFrame (snapcn) |
| **Diegetic CTA (Typing cursor)** | Terminal / Typewriter + مؤشر يومض |
| **Visual Rest** | لقطة Dynamic Typography + زوم بطيء + ارتفاع BGM |
| **Bookending Motif** | motif واحد متكرر (Neon Ring مثلاً) |
