## 2. Correct Mixed-Language Quality Metrics (`03_mixed_ar_en.wav`)

### 2.1 The Three Separated Linguistic Concepts
In previous reporting, phonetic transliteration match was colloquially designated as "0% WER". Under S28-M04.1, three mutually exclusive concepts are formally separated:

1. **A. Orthographic Ground Truth:**
   The exact, authoritative Arabic and English orthographic text intended for video subtitles and UI display:
   ```text
   السلام عليكم using the video rendering pipeline
   ```
2. **B. Canonical Model Output:**
   The literal, raw string emitted by `LocalSTTProvider` without any downstream manual re-encoding or semantic patching:
   ```text
   Assalamualaikum Using the video rendering pipeline
   ```
3. **C. Phonetic / Transliteration Equivalence (Separate Metric):**
   - **Metric Name:** `phonetic_intent_recovery`
   - **Score:** **100.0%**
   - **Definition:** Assesses acoustic phonetic coverage. The Arabic Islamic greeting ("السلام عليكم") is acoustically decoded as its standard Latin transliteration ("Assalamualaikum"), while the English clause ("using the video rendering pipeline") matches 5 out of 5 words verbatim.

### 2.2 Mathematical Calculation of Textual WER & CER

Textual Word Error Rate (WER) and Character Error Rate (CER) are computed strictly against the normalized surface strings using dynamic programming Levenshtein distance:

#### Normalization Pipeline:
1. Stripping Arabic diacritics (tashkeel: fathah, dammah, kasrah, sukun, shaddah).
2. Normalizing Alef variants (`[إ, أ, آ, ٱ]` -> `ا`).
3. Normalizing Ta Marbuta (`ة` -> `ه`) and Alef Maksura (`ى` -> `ي`).
4. Removing tatweel (kashida).
5. Stripping all punctuation (`[،؛؟!\?.,:;\-\"'\(\)\[\]\{\}\<\>/\\]`).
6. Lowercasing Latin characters.
7. Collapsing multiple spaces into a single space.

#### Normalized Strings:
- **Reference:** `'السلام عليكم using the video rendering pipeline'`
- **Hypothesis:** `'assalamualaikum using the video rendering pipeline'`

#### Detailed Token-Level Edit Operations:
- **Reference Words ($N = 7$):** `['السلام', 'عليكم', 'using', 'the', 'video', 'rendering', 'pipeline']`
- **Hypothesis Words ($M = 6$):** `['assalamualaikum', 'using', 'the', 'video', 'rendering', 'pipeline']`
- **Edit Operations:**
  - Substitution 1: `'السلام'` replaced by `'assalamualaikum'` ($S = 1$)
  - Deletion 1: `'عليكم'` deleted ($D = 1$)
  - Exact Matches (5): `'using'`, `'the'`, `'video'`, `'rendering'`, `'pipeline'`
  - Insertions: $I = 0$
  - Total Errors: $S + D + I = 2$

$$\text{Textual WER} = \frac{S + D + I}{N} = \frac{1 + 1 + 0}{7} = \frac{2}{7} \approx \mathbf{28.57\%} \quad (0.2857)$$

#### Character-Level Edit Operations:
- **Reference Characters ($N = 47$ with spaces, $N = 41$ without spaces):**
- **Edit Operations (with spaces):**
  - Substitutions ($S$): 12
  - Deletions ($D$): 0
  - Insertions ($I$): 3
  - Total Errors: 15

$$\text{Textual CER}_{\text{with spaces}} = \frac{15}{47} \approx \mathbf{31.91\%} \quad (0.3191)$$
$$\text{Textual CER}_{\text{without spaces}} = \frac{15}{41} \approx \mathbf{36.59\%} \quad (0.3659)$$

### 2.3 Quality Classification & Root Cause Analysis

- **Authoritative Classification:** **`KNOWN_MIXED_LANGUAGE_LIMITATION`**
- **Technical Explanation:**
  1. **Single-Pass Global Language Identification:** `faster-whisper` samples audio frames from the initial window and computes language log-probabilities. For `03_mixed_ar_en.wav`, it detected `<|en|>` with probability `0.4317` (versus `<|ar|>` with probability `0.1105`).
  2. **Script Suppression in Decoder:** When the Whisper decoder is initialized with the `<|en|>` language token, it restricts vocabulary logits toward Latin subwords. When processing the Arabic acoustic frames, the model decodes the acoustic phonemes into Latin transliteration (`Assalamualaikum`) rather than switching tokenizers to Arabic Unicode codepoints (`السلام عليكم`).
  3. **Absence of Segment-Level Language Metadata:** In CTranslate2 `faster-whisper`, the `Segment` namedtuple attributes are:
     ```python
     ['avg_logprob', 'compression_ratio', 'end', 'id', 'no_speech_prob', 'seek', 'start', 'temperature', 'text', 'tokens', 'words']
     ```
     CTranslate2 does **not** provide per-segment language classification. The language attribute is exclusively global on `TranscriptionInfo`.
- **Architectural Policy:** We do NOT alter model weights, switch to a larger model, or inject brittle regular expression transliterators in M04. The limitation is recognized as a known acoustic boundary of single-pass Whisper base on mixed code-switched audio.

## 3. Platform Artifact Authority & Storage Boundary (Option B)

Audit question: Does `TranscriptArtifact` represent a parallel domain authority competing with `ArtifactService`?

### Formal Resolution:
1. **Domain Sovereign:** `ArtifactService` remains the **sole, platform-wide domain authority** for persistent assets, project schemas, and durable artifact registration.
2. **Transient Analytical Schema:** In milestone S28-M04, `TranscriptArtifact` in `ai/speech/adapter.py` is strictly a transient Pydantic data structure representing structured speech intelligence (words, segments, timestamps, confidence scores).
3. **Internal Cache Helper:** `STTCacheManager` in `ai/speech/cache.py` is strictly an internal LRU/memory cache helper (implementing `AICacheKeyParams` under `ArtifactService / Transient Analysis Cache`). It serves solely to cache intermediate model responses by content hash to prevent redundant CPU cycles.
4. **Deferred to S28-M07:** Full database persistence, domain event publication, and permanent cataloging of speech timeline manifests (`SpeechIntelligence` / `TranscriptManifest`) are scheduled as a subtask/concern within **S28-M07 — Audio Tool Modernization**.

No competing authority or duplicate database table exists.
