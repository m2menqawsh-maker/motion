## 1. Scope & Objective

Milestone S28-M02.1 executes a surgical hardening patch across the Capability Taxonomy and Contract system prior to the commencement of S28-M03. It resolves four specific structural and integrity gaps identified during the M02 audit:
1. **Multi-Side-Effect Representation:** Enables capabilities to accurately declare compound side-effects (e.g., subprocess execution + persistent writes).
2. **TenantScope Consistency:** Aligns `TenantScope` to represent caller authorization and resource isolation scope, ensuring all Project Asset operations are strictly `PROJECT` scoped and eliminating contradictory permission/scope combinations.
3. **Input / Output Contract Referential Integrity:** Establishes concrete canonical Pydantic models for all 32 input contracts and 32 output contracts, eliminating all 62 dangling contract references.
4. **Storage Boundary Normalization:** Strictly separates the canonical `target_storage_boundary` (governed by architectural authorities such as `StorageService`, `AssetService`, `ArtifactService`, `RunService`) from historical `legacy_storage_behavior`.

## 3. Side-Effect Model: Before vs. After

| Aspect | Before (S28-M02) | After (S28-M02.1) | Architectural Gain |
|---|---|---|---|
| **Contract Field** | `side_effect_class: SideEffectClass` (Scalar) | `side_effects: list[SideEffectClass]` (Array) + synchronized `side_effect_class` | Can declare multiple effects simultaneously without information loss. |
| **`TRIM_VIDEO`** | `SUBPROCESS` only | `[SUBPROCESS, PERSISTENT_WRITE]` | Explicitly captures file generation as well as subprocess spawning. |
| **`DOWNLOAD_REMOTE_MEDIA`** | `PERSISTENT_WRITE` only | `[PERSISTENT_WRITE, EXTERNAL_NETWORK]` | Captures outbound network egress requirement and storage mutation. |
| **`CHANGE_VIDEO_SPEED`** | `PERSISTENT_WRITE` only | `[PERSISTENT_WRITE, SUBPROCESS, BACKGROUND_JOB]` | Captures asynchronous background job lifecycle + local transcoding. |
| **`MUTATE_ASSET_STATUS`** | `DOMAIN_MUTATION` only | `[DOMAIN_MUTATION, PERSISTENT_WRITE]` | Captures database/manifest state transition + manifest file serialization. |
| **`SEARCH_ICONS`** | `EXTERNAL_NETWORK` only | `[EXTERNAL_NETWORK, READ_ONLY]` | Distinguishes read-only external queries from mutating network calls. |
| **Backward Compatibility** | N/A | Bidirectional `@model_validator(mode="before")` | Providing `side_effect_class` populates `side_effects`; providing `side_effects` sets primary `side_effect_class`. |
| **Deduplication** | None | Automatic preserving order | Prevents duplicate enum values in side effects array. |

## 4. TenantScope Consistency & Corrections

### 4.1 Boundary Principle Applied
`TenantScope` represents the **caller authorization and resource isolation scope** of the capability, NOT whether the external provider is public or private.

### 4.2 Detailed Corrections

|---|---|---|---|
| `TRIM_AUDIO`, `EXTEND_AUDIO`, `NORMALIZE_AUDIO_LOUDNESS`, `TRIM_AUDIO_SILENCE` | `WORKSPACE` | **`PROJECT`** | Operates directly on Project Assets (`projects/{project_id}/audio/`). |
| `TRIM_VIDEO`, `EXTEND_VIDEO`, `RESIZE_VIDEO`, `TRIM_BLACK_FRAMES`, `CHANGE_VIDEO_SPEED`, `ENFORCE_KEYFRAME_INTERVAL`, `CONCATENATE_VIDEOS` | `WORKSPACE` | **`PROJECT`** | Operates directly on Project Assets (`projects/{project_id}/video/`). |

| `DOWNLOAD_REMOTE_MEDIA`, `EXTRACT_MEDIA_PAGE`, `DOWNLOAD_ICON` | `WORKSPACE` | **`PROJECT`** | Ingests media payloads directly into project storage trees. |
| `INSPECT_MEDIA` | `WORKSPACE` | **`PROJECT`** | Probes project media assets. |
| `SPEECH_TO_TEXT`, `SEGMENT_SPEECH_AUDIO` | `WORKSPACE` | **`PROJECT`** | Transcribes and slices project voiceover audio. |

| `SEARCH_STOCK_IMAGES`, `SEARCH_STOCK_VIDEOS`, `SEARCH_STOCK_AUDIO`, `SEARCH_SOUND_EFFECTS` | `WORKSPACE` | **`WORKSPACE`** | Verified: queries require workspace API keys and rate-limit governance. |
| `MUTATE_ASSET_STATUS`, `CHECK_MEDIA_CACHE`, `STORE_MEDIA_CACHE`, `GET_JOB_STATUS`, `CANCEL_PROCESSING_JOB` | `PROJECT` | **`PROJECT`** | Verified: state transitions are strictly scoped to `projects/{project_id}`. |

### 4.3 Invariant Enforcement Added
The model validator `validate_capability_invariants` strictly blocks contradictory combinations:
1. `(DOMAIN_MUTATION in side_effects or PERSISTENT_WRITE in side_effects) and tenant_scope == NONE` -> **REJECTED**
2. `(DOMAIN_MUTATION in side_effects or PERSISTENT_WRITE in side_effects) and not any(p in required_permissions for p in ['editor', 'admin'])` -> **REJECTED**
3. `tenant_scope == NONE and any(p in required_permissions for p in ['editor', 'admin'])` -> **REJECTED**

## 6. Storage Boundary Normalization: Before vs. After

### 6.1 Architectural Decoupling
| Capability Level | Implementation Level |
|---|---|
| **`target_storage_boundary`** | **`legacy_storage_behavior`** |
| Declares the authoritative subsystem governing storage | Documents historical unconfined filesystem technical debt |
| Points to domain architectural authorities (`StorageService`, `AssetService`, `ArtifactService`, `RunService`) | Points to raw paths (`reads/writes via FFmpeg streamcopy`, `creates ad-hoc .{stem}.analysis.json`) |
| Strictly enforced: Raw filesystem paths prohibited | Preserved for migration fidelity and auditing |

### 6.2 Architectural Authority Distribution
- **`StorageService` (17 Capabilities):** Governs media blobs (project audio, video, images, slices, icons, remote ingest).
- **`AssetService` (3 Capabilities):** Governs domain assets (`ManifestV2 Authority`, `Managed Cache Hierarchy`).
- **`ArtifactService` (3 Capabilities):** Governs analytical artifacts (`Transient Analysis Cache`, `Speech Manifest`, `Speech Timeline`).
- **`RunService` (2 Capabilities):** Governs process state (`Durable Job Record`).
- **`Stateless In-Memory API` (5 Capabilities):** Governs external search queries without disk writes.

## 7. Failures Found & Repaired During Hardening

1. **Failure 1 — Contradictory TenantScope in `SEARCH_ICONS`:**
   - *Discovery:* The new model validator failed when validating `CAPABILITY_CATALOG.json`: `Capability 'SEARCH_ICONS' has tenant_scope=NONE but requires tenant-specific permissions '['viewer', 'editor']'`.
   - *Repair:* `SEARCH_ICONS` was corrected to `tenant_scope: WORKSPACE`, as icon search runs in an authenticated workspace session.
2. **Failure 2 — Mutation on Frozen Model in Validator:**
   - *Discovery:* Pydantic raised `pydantic_core._pydantic_core.ValidationError: Instance is frozen` when trying to modify `self.side_effects` inside `mode="after"` validator.
   - *Repair:* Moved normalization and deduplication to `@model_validator(mode="before")` `sync_side_effects`, keeping `mode="after"` validator purely for invariant checks.
3. **Failure 3 — NameError in Referential Integrity Test:**
   - *Discovery:* `AIContractModel` was missing from top-level test imports in `test_capability_taxonomy_and_contracts.py`.
   - *Repair:* Added `AIContractModel` to imports.
