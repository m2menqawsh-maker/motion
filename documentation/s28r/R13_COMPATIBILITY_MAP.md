## 2. API Migration Summary

### Before R13 (Fragmented / Competing Authoring):
- AI agents attempted direct JSON manipulations or generated Remotion TSX code.
- User edits in the editor risked being clobbered if the AI re-compiled the creative plan.
- Templates were rigid or re-instantiated completely, resetting user adjustments.

### After R13 (Unified Authoring):
- AI intents are submitted via `AuthoringRequest` to `UnifiedAuthoringSession.executeRequest()`.
- Pure `planAuthoringIntent()` translates intents to typed `CanonicalMutation[]`.
- Stable IDs (`scene_id`, `layer_id`, `clip_id`) guarantee precise targeting.
- Optimistic concurrency control (`base_revision`) guards against silent overwrite races.
- Compound commands support single-step atomic undo/redo.
- Zero TSX, Remotion, Canvas, or FFmpeg code is generated by the AI authoring layer.
